
# TSLANet: Machine Learning Strategy for NIFTY 50 Trading

## Overview
TSLANet predicts directional moves in NIFTY 50 using 5-minute data with SSL Hybrid and WAE indicators.

## Key Results
- Test Accuracy: 83.7%
- Trades: 1,149
- Win Rate: 51.6%
- Profit Factor: 1.40
- Total Return: 37.95%
