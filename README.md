# ML Strategy for NIFTY 50 Trading

## Overview
This project presents a machine learning strategy for NIFTY 50 trading. The strategy uses 5-minute data with SSL Hybrid and Waddah Attar Explosion V3 indicators.

## Key Results
- **Test Accuracy:** 86.9%
- **Trades:** 1,149
- **Win Rate:** 51.6%
- **Profit Factor:** 1.40
- **Total Return:** 37.95% (2.5 months)
